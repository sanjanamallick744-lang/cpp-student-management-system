# Student Management System

A basic Student Management System developed using C++.

## About the Project

This project is a simple command-line application designed to manage basic student information. It allows the user to enter and display student details such as roll number, name, and marks.

## Features

- Enter student details
- Display student information
- Store student roll number, name, and marks
- Calculate Pass/Fail result
- Simple command-line interface

## Technologies Used

- C++

## Concepts Used

- Structures
- Variables
- Conditional Statements
- User Input and Output
- Strings
- Basic Programming Logic

## How to Run

1. Download the source code.
2. Open the `.cpp` file in a C++ IDE.
3. Compile the program.
4. Run the program.
